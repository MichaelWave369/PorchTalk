# PorchTalk

**Ask locally. Collaborate by choice.**

PorchTalk is the proposed local-first, consent-governed, budget-aware model routing layer for Infinite Porch and Infinite Commons.

The first offline policy prototype is being developed on a review branch. No peer networking, model inference, or resource-sharing is enabled by this repository's default branch yet.
